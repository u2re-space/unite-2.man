# CWSP Projects Family

There is few chapters...

- `CWSP-document` - utilities, toolsets for markdown, image viewing and AI processing... early was `CrossWord`, PWA application mode available, will be in `CWSP-crx`, in Capacitor, Neutralino editions...
- `CWSP-transfer` - sharing clipboard, transfering files (uses frontend, and backends), early was as `CWSP-reborn`, isn't PWA application itself
- `CWSP-crx` - chrome extension, combines features from CWSP-document, CWSP-transfer and CWSP-shell, isn't PWA application itself, but is chrome-extension was present
- `CWSP-shell` - web-desktop, modile-launcher alikes speed dial, will be dedicated project and chrome extenions for new tab page, will be available as PWA, borderless, transparent, Neutralino, Capacitor, etc. Also will have sub-option for borderless window per opened inside app or page.
- `CWSP-explorer` - file manager, explorer, for multiple platforms and backends, will be available as PWA, Capacitor, Netralino.
- `CWSP-direct` - (PLANNED) remote control toolset, such as KVM, AirPad, Remote Accesses, isn't PWA byself, but partially compatible, also will be in Capacitor, Neutralino, with dedicated backends from `CWSP-transfer`. Planned as separate project due of weakness of `CWSP-transfer` protocol, and difficults on implementation of such things.
- `CWSP-shared` - shared extras for other `CWSP` projects (such as AI libs, DOCX, opfs helpers, service workers libs).
